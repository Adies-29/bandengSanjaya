## ⚡ Kategori 2: Technical & Speed SEO (Kecepatan & Performa)
*Memastikan website super cepat, ringan, dan ramah pengguna mobile.*

- [x] **Native Lazy Loading (`loading="lazy"`)**
  - **Status:** Done (Semua gambar katalog, slider, dan footer menggunakan lazy loading agar website cepat terbuka).
- [x] **Async Image Decoding (`decoding="async"`)**
  - **Status:** Done (Mencegah browser patah-patah saat pengguna melakukan scroll).
- [x] **Tampilan Mobile Responsive & Theme Color**
  - **Status:** Done (Tampilan rapi di smartphone & warna header browser disesuaikan `#ecffdb`).
- [ ] **Kompres File Gambar PNG Besar ke Format `.webp`**
  - **Instruksi:** Beberapa gambar PNG berukuran >5MB (seperti `bandeng-presto.png` dan `pepes-bandeng.png`) disarankan dikompres gratis di [TinyPNG](https://tinypng.com) atau [Squoosh](https://squoosh.app) menjadi format `.webp`.
- [ ] **Daftarkan Website ke Google Search Console**
  - **Instruksi:** Setelah website di-publish (online), daftarkan URL ke [Google Search Console](https://search.google.com/search-console) lalu klik *Request Indexing*.
